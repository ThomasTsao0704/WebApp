產業分類來源 Google Sheet + Apps Script
會呼叫 ?action=bootstrap&format=map 一次取回「代號→產業」對照與大分類規則， 並用 ?action=meta 的 version 做版本比對，版本沒變就直接用本機快取。 「新增產業資訊」會寫入 industry_map，同一個代號會覆蓋既有那一列。 Apps Script 部署時請選「任何人（含匿名）可存取」，不需要 CORS Proxy。
產業對應表 API 沒有 industry 欄位時的備援
產業別的判斷順序是：營收 API 的 industry 欄位 → 產業 API 同步下來的對照 → 這裡手動貼上的對應表 → 未分類。
產業大分類規則
欄位定義
MoM%：當月營收 ÷ 上月營收 − 1，短期動能，受淡旺季影響大。
YoY%：當月營收 ÷ 去年同月營收 − 1，排除季節性，最常用來看趨勢。
累計YoY%：今年累計 ÷ 去年同期累計 − 1，波動較小，代表全年方向。
連續：API 的 grow_month／decline_month，連續成長或衰退的月數。
新高：is_new_high 為近 12 月新高，ATH 為歷史新高。
營收門檻：小公司基期極低時 YoY 會出現數千％的失真值，建議至少保留 1 千萬門檻。
加權年增：產業當月營收合計 ÷ 去年同月合計 − 1。看得出產業「總量」的變化，但會被龍頭主導。
中位年增：產業內個股年增率的中位數，代表典型公司。與加權差距大＝成長集中在少數股。
成長家數占比：年增為正的家數 ÷ 有年增數字的家數，衡量成長的廣度。
年增貢獻 pp：（個股當月營收 − 去年同月）÷ 產業去年同月合計，單位百分點； 全產業加總正好等於加權年增，可看出成長是誰帶起來的。
前三大集中度：營收前三大成分股占產業營收比重。
產業趨勢：以營收前 10 大成分股的歷史月營收合計而成，非完整產業總額，僅供看方向。
