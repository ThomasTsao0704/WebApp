# 📊 股票分析系統 v4.0 - 完整使用指南

## 系統概覽

你現在擁有一個完全自包含的多頁面股票分析系統。每個 HTML 文件都是獨立的，包含了所有需要的 CSS 樣式和 JavaScript 功能代碼。這個系統採用了模組化架構，但不依賴於任何構建工具或複雜的導入系統。所有數據都通過瀏覽器的 localStorage 在頁面之間共享。

## 文件結構

```
stock-analysis-system/
├── index.html              # 📌 主導航首頁
├── upload.html             # 📤 數據上傳（支持 CSV/Excel）
├── dashboard.html          # 📈 儀表板（市場概況）
├── limitup.html           # 🔥 限漲股排行
├── concepts.html          # 🎯 概念股分析
├── analyze.html           # 📊 成交分析（K線圖表）
├── portfolio.html         # 💼 投資組合管理
├── alerts.html            # ⏰ 價格警示設置
├── records.html           # 📝 投資紀錄
├── search.html            # 🔍 全局搜尋
└── compare.html           # ⚖️ 股票對比
```

## 核心特性

### 1. 完全本地化存儲
所有數據都保存在你的瀏覽器本地存儲中，包括市場數據、投資紀錄、投資組合、價格警示等。這意味著：
- 無需上傳到任何服務器
- 完全的隱私保護
- 沒有任何跟蹤或監控
- 可以完全離線使用

### 2. 獨立頁面架構
每個功能模組都是獨立的 HTML 頁面，可以單獨使用或集成到其他系統中。頁面之間通過以下方式共享數據：
- localStorage（用於持久化存儲）
- URL 查詢參數（用於頁面導航傳遞信息）
- 相同的存儲鍵值命名約定

### 3. 深色/淺色主題
整個系統支持深色和淺色主題的自動切換。主題偏好保存在 localStorage 中，所有頁面都會讀取這個設置。

### 4. 響應式設計
所有頁面都使用現代的 CSS Grid 和 Flexbox 佈局，完美適配桌面、平板和手機設備。

## 詳細功能說明

### 📌 主導航首頁 (index.html)
這是你的起點，展示所有可用的功能模組。它提供：
- 系統功能概覽
- 快速導航到各個功能頁面
- 使用說明
- 系統特性介紹

### 📤 數據上傳 (upload.html)
這是最重要的一個功能。使用此頁面上傳你的股票市場數據。功能包括：
- 支持 CSV 和 Excel（XLSX）格式
- 自動解析和驗證數據
- 三種合併策略：
  - 智能合併（去重）：檢測重複的「股票代碼+日期」組合，保留最新的版本
  - 完全覆蓋：用新數據完全替換現有數據
  - 直接追加：簡單地在現有數據後面添加新數據
- 實時展示數據統計（總筆數、日期範圍、股票家數）

數據格式應包含以下列（列名可以是中文或英文）：
日期、代碼、商品（名稱）、收盤價、漲跌幅、成交量、開盤價、最高價、最低價

### 📈 儀表板 (dashboard.html)
這是你查看市場概況的地方。系統會自動分析最新日期的數據，展示：
- 上漲家數和下跌家數
- 平均漲跌幅
- 成交量前五的股票
- 漲幅前五的股票

所有的股票代碼都是可點擊的，點擊後會自動跳轉到成交分析頁面進行詳細分析。

### 🔥 限漲股排行 (limitup.html)
按照漲幅排序展示今日前 20 名強勢股。這個頁面幫助你快速發現市場中的機會股票。

### 🎯 概念股分析 (concepts.html)
按照預定義的概念分類展示股票。系統預設了四個主要概念：
- AI人工智慧
- 電動車
- 半導體
- 5G通訊

每個概念下都有相應的股票代碼列表。頁面會計算每個概念的平均漲跌幅、包含的股票家數和總成交量。你可以勾選/取消勾選概念來動態篩選展示的內容。

### 📊 成交分析 (analyze.html)
這是進行深度股票分析的工具。功能包括：
- 輸入或從儀表板跳轉選擇股票
- 自動生成 K 線圖表（使用 Chart.js）
- 展示詳細的統計數據：開盤價、收盤價、最高價、最低價、漲跌幅、數據筆數
- 支持通過 URL 參數直接跳轉到特定股票（如 analyze.html?code=2330）

### 💼 投資組合 (portfolio.html)
記錄和管理你的持股情況。功能包括：
- 新增持股（代碼、數量、成本價）
- 實時計算：
  - 現價（從最新市場數據中獲取）
  - 現值（現價 × 數量）
  - 損益（現值 - 成本）
- 顯示組合的總值和總損益

### ⏰ 價格警示 (alerts.html)
設置股票價格提醒。功能包括：
- 設置上限價格（≥）：當股票達到或超過此價格時觸發
- 設置下限價格（≤）：當股票跌到或低於此價格時觸發
- 實時監控狀態：「觸發」或「—」

### 📝 投資紀錄 (records.html)
記錄你的投資決策和分析筆記。功能包括：
- 日期、股票代碼、備註
- 所有紀錄按日期倒序展示
- 方便查看歷史決策

### 🔍 全局搜尋 (search.html)
快速搜尋股票。功能包括：
- 實時搜尋（隨著輸入自動更新結果）
- 支持按代碼或名稱搜尋
- 最多展示 100 條搜索結果
- 搜索結果中的股票可點擊進入成交分析

### ⚖️ 股票對比 (compare.html)
同時對比多隻股票的走勢。功能包括：
- 輸入多個股票代碼（支持空白、逗號、分號分隔）
- 為每隻股票展示最近 30 天的數據
- 包括日期、收盤價、漲跌幅等信息

## 技術架構

### 存儲鍵值約定

所有數據都使用以下鍵值存儲在 localStorage 中：

- `stockMarketData_v3`：市場數據（數組）
- `stockPortfolio_v3`：投資組合（數組）
- `stockRecords_v3`：投資紀錄（數組）
- `priceAlerts_v3`：價格警示（數組）
- `theme_dark`：主題設置（'1' 表示深色，'0' 表示淺色）

### 數據格式

市場數據的標準格式：
```json
{
  "version": "2.0",
  "lastUpdate": "2024-01-15T10:30:00.000Z",
  "recordCount": 1000,
  "data": [
    {
      "日期": "2024-01-15",
      "代碼": "2330",
      "商品": "台積電",
      "收盤價": 623.0,
      "漲跌幅": 2.5,
      "成交量": 12345678,
      "開盤價": 610.0,
      "最高價": 625.0,
      "最低價": 608.0
    }
  ]
}
```

### 第三方庫

只有數據上傳和成交分析頁面需要外部庫：
- PapaParse（CSV 解析）：https://cdnjs.cloudflare.com/ajax/libs/PapaParse/5.4.1/papaparse.min.js
- XLSX（Excel 解析）：https://cdnjs.cloudflare.com/ajax/libs/xlsx/0.18.5/xlsx.full.min.js
- Chart.js（圖表繪製）：https://cdn.jsdelivr.net/npm/chart.js@4.4.1/dist/chart.umd.min.js

這些庫都是通過 CDN 加載的，無需本地安裝。

## 常見問題

**Q：我的數據會被保存在哪裡？**
A：所有數據都保存在你瀏覽器的 localStorage 中。如果你清除瀏覽器緩存，數據會被刪除。建議定期導出備份。

**Q：支持多少筆數據？**
A：localStorage 通常支持 5-10MB 的數據。對於大多數個人投資者來說足夠了。如果數據超過限制，會收到存儲滿的警告。

**Q：可以在多個設備上使用嗎？**
A：由於數據存儲在本地，不同設備的數據是獨立的。可以通過導出/導入功能在設備之間轉移數據。

**Q：如何備份我的數據？**
A：目前你可以通過瀏覽器的導出功能手動導出 localStorage 數據。建議定期導出重要數據以防萬一。

**Q：系統支持股票期權或期貨嗎？**
A：當前系統主要針對股票設計。如果你需要支持其他資產類型，可以修改數據格式和相應的解析邏輯。

**Q：可以添加新的概念股嗎？**
A：可以的。編輯 concepts.html 中的 `concepts` 對象，添加新的概念名稱和相應的股票代碼列表。

## 性能優化建議

為了獲得最佳性能，考慮以下建議：

1. **定期清理舊數據**：隨著時間積累，localStorage 可能變滿。定期導出重要數據並清空舊數據。

2. **使用現代瀏覽器**：Chrome、Firefox、Edge 等都提供最佳的 localStorage 支持和性能。

3. **避免過大的數據集**：如果一次性導入大量數據，分多次進行可能會更快。

4. **離線使用**：系統可以完全離線使用。首次加載後，所有功能都可在沒有網絡連接的情況下工作（除非需要加載新的 Chart.js 圖表）。

## 故障排除

**症狀：新增的數據沒有出現**
- 解決方案：檢查 localStorage 是否已滿。在瀏覽器設置中清除緩存或導出數據后重新導入。

**症狀：圖表無法顯示**
- 解決方案：確保 Chart.js 已從 CDN 加載。檢查網絡連接。

**症狀：主題切換後沒有變化**
- 解決方案：刷新頁面。確保 localStorage 未被禁用。

**症狀：某個頁面無法加載**
- 解決方案：檢查文件是否存在且路徑正確。查看瀏覽器控制台是否有錯誤信息。
