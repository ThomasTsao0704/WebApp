## 立即使用（最簡單）

1. **解壓縮檔案**到任意資料夾
2. **雙擊開啟** `index.html` 檔案
3. ✅ 完成！開始使用

---

## 使用本地伺服器（推薦）

### Windows 使用者

#### 方法 1: 使用 Python
```bash
# 開啟命令提示字元 (CMD) 或 PowerShell
# 切換到專案資料夾
cd C:\path\to\thomas-japan-travel

# 啟動伺服器
python -m http.server 8000
```

#### 方法 2: 使用 Node.js
```bash
# 安裝 http-server (只需執行一次)
npm install -g http-server

# 啟動伺服器
http-server -p 8000
```

### Mac / Linux 使用者

```bash
# 開啟終端機
# 切換到專案資料夾
cd ~/path/to/thomas-japan-travel

# 啟動伺服器
python3 -m http.server 8000
```

### 開啟瀏覽器

在瀏覽器輸入：`http://localhost:8000`

## ❓ 常見問題

### Q: 為什麼要使用本地伺服器？
A: 某些功能（如 Service Worker）需要在 HTTP/HTTPS 環境下才能運作，直接開啟檔案可能會有限制。

### Q: 可以離線使用嗎？
A: 可以！首次載入後，所有功能都可以在離線狀態下使用。

### Q: 如何更新景點資料？
A: 編輯 `data/trip.json` 檔案即可新增或修改景點。

### Q: 支援哪些瀏覽器？
A: 支援所有現代瀏覽器：
- Chrome / Edge (推薦)
- Safari
- Firefox
- Opera
