萬用轉圖檔工具 Any → PNG

上傳幾乎任何常見格式的檔案，自動轉成 PNG／JPG／WebP 圖片。PDF 使用 PDFium WebAssembly 渲染；檔案本身不會上傳到你的伺服器。

PDF · PDFium JPG / PNG / GIF / BMP / WebP / SVG / ICO Word (.docx) Excel (.xlsx/.xls/.csv) PowerPoint (.pptx)† 純文字／程式碼 (.txt/.md/.js/.py/.json…)
點擊選擇檔案，或拖曳到此處
支援一次選擇多個檔案、多種格式混合上傳
僅影響 PDF／文件／文字類；一般圖片維持原始解析度
可用 {name}=原檔名, {n}=頁碼

PDF 轉圖使用 PDFium（ClawPDF），針對向量、透明度、裁切路徑與複雜印刷型 PDF 提供較完整的原生 PDF 渲染。

† PowerPoint 為簡化版轉換：會擷取每張投影片的文字與圖片重新排版成畫面，版面配置不會與原始簡報完全一致。
不支援：舊版二進位格式 (.doc/.ppt/.xls)、影片、音訊、壓縮檔等需要專用解碼器的格式。
